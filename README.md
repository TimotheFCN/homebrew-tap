# homebrew-tap

Homebrew formulae for [rbw-ng](https://github.com/TimotheFCN/rbw-ng), the
maintained continuation of `rbw`, the unofficial Bitwarden CLI.

```sh
brew install timothefcn/tap/rbw-ng
```

The release workflow of rbw-ng updates `Formula/rbw-ng.rb` on every release.
Report problems in the [rbw-ng issue
tracker](https://github.com/TimotheFCN/rbw-ng/issues).
